## 先分清：裸金属服务器不是"性能更好的云服务器"

裸金属服务器（Bare Metal Server，BMS）也叫物理机、独立服务器，指的是不经过虚拟化层、直接把一台物理机器的硬件资源交给单个租户的产品。没有 KVM，没有超分，没有邻居抢你的 CPU 时间片。

雨云官方文档里打了个比方：云服务器像合租公寓，设施共享、随时换房；裸金属像整栋别墅，没有二房东在中间。

| 产品形态 | 特点 | 交付方式 |
| --- | --- | --- |
| 云服务器 | 创建快、规格灵活，适合网站、轻量应用、测试环境 | 分钟级，自服务 |
| 裸金属物理机 | 资源独占、性能稳定，支持自动化部署和远程控制台 | 自动化交付，权限接近云主机 |
| 传统物理机 | 资源完全独占，但交付周期按天/周计，需人工布线装机，故障排查慢 | 人工上架 |

关键差异在最后一行。传统物理机慢的不是性能，是流程：上架等人、装机等人、坏了还得等人。裸金属服务器存在的意义就是把物理机的性能和云主机的交付速度拼在一起。

顺便说一句鉴别方法：市面上确实有商家把基于虚拟化的 VPS 换个名字叫"裸金属"卖。雨云在自家论坛的公告里专门点过这件事。你可以在买到之后进系统看 CPU 型号和 `lscpu` 的虚拟化标志，或者看能不能自己进 BIOS——真物理机能进，VPS 进不去。

## 挑机器前先确认这四件事

**1. 你要单核性能还是多核性能**

这是最容易选错的一项。E5-2680v4 双路能给你 28 核 56 线程，丢到跑分软件里多核分数很好看，但单核只有 392 分（CPU-Z，第三方测评数据）。换一台 i7-14700HX，物理核心少一半，单核能到 911 分。

跑 Minecraft 服务端、跑单线程密集的编译任务、跑响应敏感的 Web 后端——这些场景里，56 个慢核心不如 8 个快核心。反过来，多开容器、批量转码、跑分布式任务，核心数才有意义。

**2. 大带宽限流量，还是小带宽不限流量**

雨云大部分裸金属机型提供这两种形态，**价格一样**，选哪个看你业务峰值。大带宽型给到 500Mbps，但流量按月扣；不限流量型带宽砍半（比如 500M 的机型给 50M 上传）。

流量用完了不会停机，会限速到 5Mbps，想恢复高速得买流量包。宁波机型是 35 元 1TB，深圳机型是 100 元 1TB——同样是流量包，区域差了三倍，下单前先看一眼你选的那个区域。

**3. 防御是自带的还是要加购 IP**

有些机型的价格里已经含了高防 IP（比如宁波部分机型配 100G 电信防御，十堰机型默认 1 个高防 IPv4，深圳部分机型默认含高防 IP），有些是不含的，加购按个收费，宁波普通 IP 30 元/个。差两个 IP 就是每月 60 元，别看漏。

**4. 计费周期**

月付最贵，季付 8 折，半年付和年付 7 折。这是雨云官方文档里写明的规则，定制配置项也能享受同样的折扣。

## 有争议的地方也得说

在 LINUX DO 论坛有一篇讨论雨云服务器问题的长帖，作者描述了自己的经历：深圳电信单线机器对移动用户上传速度差，运营商侧存在 QoS；服务器出现过间歇性断连；其中一次故障官方给出的原因是内存溢出排查后认定为线路松动，赔偿方案是按中断时长的 168 倍计算，折合 7 天。

这类反馈不代表你一定会遇到同样的情况，但它说明两件事：第一，便宜的大带宽单线机型在跨网质量上确实有妥协，移动用户选 BGP 线路更稳；第二，真出问题时，赔偿是按时长倍数算的，不是按业务损失算的。如果你的业务停一小时就损失惨重，这个风险要提前评估。

另外几条实操上的限制也值得记一下：7 天无理由退款每个账号限 3 次，不是无限退；流量用超了会限速而不是停机，恢复要买流量包；IP 加购按个收费，多个高防 IP 的成本会叠加。

## 常见问题

**裸金属服务器和云服务器，哪个更划算？**

同价位的裸金属通常能给到更多核心和内存，因为省掉了虚拟化的资源开销。但云服务器可以随时升降配、按小时计费，裸金属的规格调整没那么灵活。短期项目、流量波动大的业务，云服务器或者游戏云的动态计费更合适。

**雨云的裸金属能自己装系统、开虚拟化吗？**

可以。物理机没有虚拟化限制，你能进 BIOS、能装任何支持的操作系统，也能在机器上再开 KVM 跑虚拟化。官方提供的系统镜像只是自动化装机的一环，不是强制选项。

**20 元试用 1 天，能测出什么？**

能测出硬件是不是你预期的型号、磁盘读写多少、网络延迟对你所在的运营商好不好、跑分大概什么水平。测不出长期稳定性。真要验证稳定性，试用之后先按月付，别一上来就买年付。

**年付 7 折划算吗？**

按 440 元/月的机型算，年付省下的是 1584 元。如果你只是短期试水，月付多花的钱就是买灵活性。已经跑起来、确定要用一年以上的业务，年付没理由不选。
